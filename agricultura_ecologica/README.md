# II Congreso de Agricultura Ecológica

Sitio web informativo y adaptable para el **II Congreso de Agricultura Ecológica**, estructurado en tres páginas y tres secciones internas en la página principal.

## Enfoque del proyecto

- **Estructura y navegación:** tres páginas interconectadas y tres secciones internas en la vista principal para organizar la información del congreso de forma clara.
- **Maquetación y posicionamiento:** uso de `position`, **Flexbox** y **CSS Grid** para resolver la distribución de componentes y bloques.
- **Interacción visual:** implementación de **transiciones y animaciones CSS** orientadas a mejorar la fluidez y la respuesta visual de la interfaz.
- **Diseño responsive:** aplicación de **media queries** para adaptar el diseño a distintos tamaños de pantalla sin perder coherencia ni caer en microajustes innecesarios por resolución.
- **Calidad y depuración:** revisión continua con las herramientas de desarrollador del navegador (`F12`, inspección de *Layout* y *Toggle Device Toolbar*) y validación de código con los validadores de **HTML y CSS del W3C**.

## Tecnologías

- **HTML5**
- **CSS3**
- **W3C Markup / CSS Validation** y **DevTools** del navegador

## Cómo visualizarlo

1. Clone o descargue el repositorio en su equipo.
2. Abra el archivo `index.html` directamente en su navegador (o ábralo con *Live Server* en VS Code).
