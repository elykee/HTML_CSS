# II Jornadas de Micología

Sitio web informativo de tres páginas en torno a unas jornadas de micología, enfocado en la estructura semántica, el control de estilos y la calidad del código.

## Enfoque del proyecto

- **Estructura HTML:** organización del contenido en tres páginas utilizando etiquetas semánticas para dar claridad y sentido estructural al documento.
- **Fundamentos de CSS:** aplicación de cascada, especificidad y herencia para controlar el comportamiento de los estilos en los distintos elementos.
- **Depuración y calidad:** revisión de estilos y estructura con las herramientas del navegador (`F12`) y validación del código mediante los validadores **HTML y CSS del W3C**.
- **Áreas de mejora identificadas:** margen de evolución en aspectos de diseño *responsive* y accesibilidad web.

## Tecnologías

- **HTML5** 
- **CSS3** 
- **W3C Markup / CSS Validation** y **DevTools** del navegador

## Cómo visualizarlo

1. Clone o descargue el repositorio en su equipo.
2. Abra el archivo `index.html` directamente en su navegador (o ábralo con *Live Server* en VS Code).
